## Controlar el tiempo

Este es el plan para tomar el control del tiempo y convertir a la Legión en la organización más poderosa del mundo:

1. Construir el Crono-Núcleo en la base lunar usando tecnología de Brainiac y Magneto.
2. Sincronizar el dispositivo con relojes públicos de Metrópolis para crear una red temporal estable.
3. Detener el tiempo durante unos minutos y trasladar los recursos estratégicos de la Legión a una ubicación segura.
4. Reiniciar el flujo temporal con un mensaje holográfico de Lex Luthor anunciando el nuevo orden mundial.
5. Usar el dispositivo únicamente para corregir errores de planificación y anticipar los movimientos de los héroes.
6. Activar el plan de escape: Mystique cambiará las identidades del equipo y todos regresarán a la base antártica antes de que el efecto termine.
