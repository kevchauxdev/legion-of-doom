# 📊 Tabla Comparativa

| Etiqueta (`[!tipo]`)                                 | GitHub | Obsidian | Descripción / Uso principal                           |
| :--------------------------------------------------- | :----: | :------: | :---------------------------------------------------- |
| **`[!NOTE]`**                                        |   ✅    |    ✅     | Información útil y general que se debe conocer.       |
| **`[!TIP]`**                                         |   ✅    |    ✅     | Consejos o mejores prácticas.                         |
| **`[!IMPORTANT]`**                                   |   ✅    |    ✅     | Información crucial para el éxito de una tarea.       |
| **`[!WARNING]`**                                     |   ✅    |    ✅     | Advertencia sobre posibles problemas o riesgos.       |
| **`[!CAUTION]`**                                     |   ✅    |    ✅     | Riesgos graves, acciones destructivas o peligros.     |
| **`[!info]`**                                        |   ❌    |    ✅     | Variante informativa (igual a *note* en Obsidian).    |
| **`[!todo]`**                                        |   ❌    |    ✅     | Tareas pendientes o listas por hacer.                 |
| **`[!abstract]`** / **`[!summary]`** / **`[!tldr]`** |   ❌    |    ✅     | Resúmenes o versiones cortas de un texto.             |
| **`[!success]`** / **`[!check]`** / **`[!done]`**    |   ❌    |    ✅     | Indicar que un proceso o tarea se completó con éxito. |
| **`[!question]`** / **`[!help]`** / **`[!faq]`**     |   ❌    |    ✅     | Preguntas frecuentes, dudas o solicitudes de ayuda.   |
| **`[!failure]`** / **`[!fail]`** / **`[!missing]`**  |   ❌    |    ✅     | Procesos fallidos o elementos que faltan.             |
| **`[!danger]`** / **`[!error]`** / **`[!bug]`**      |   ❌    |    ✅     | Errores, fallos críticos o bugs en el código.         |
| **`[!example]`**                                     |   ❌    |    ✅     | Mostrar ejemplos prácticos.                           |
| **`[!quote]`** / **`[!cite]`**                       |   ❌    |    ✅     | Citas textuales destacadas.                           |
